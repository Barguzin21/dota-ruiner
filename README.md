# Кто заруинил?

Разбор матча Dota 2 по ID: кто заруинил, кто MVP, где решился матч, карта смертей и вардов, эпизоды, номинации, билды, драфт, чат и разбор от ИИ. Плюс примерочная сетов с ценами маркета и подбором образа под бюджет.

## Как устроено

- `index.html`, `css/`, `js/` — сайт без сборки (GitHub Pages).
- `js/analyze.js` — модель: счёт влияния игрока по перцентилям OpenDota и ожиданиям роли, сигналы ошибок, руинер/MVP, эпизоды, номинации.
- `api/` — функции Vercel (`dota-ruiner.vercel.app`): `prices` (цены market.dota2.net в рублях), `ai` (Gemini, ключ `GEMINI_API_KEY`).
- `data/`, `img/` — справочники и картинки, собранные из файлов установленной Dota 2.

## Модель

Каждый игрок получает счёт 0–100 из 10–11 метрик с весами по роли (кор / саппорт): фарм, опыт, урон, смерти, цена смертей,
дисциплина (смерти без команды, перед потерей зданий, при перевесе 5k+), участие в убийствах, командные драки, добивания,
давление на здания, линия (золото к 10:00 против соперника), обзор, контроль и хил. Метрики — перцентили OpenDota на том же герое.
Руинер — худший у проигравших. «Руин %» — доля вины среди пяти проигравших, «устойчивость» — как часто он остаётся руинером
при 400 случайных наборах весов (±40%).

## 3D-примерочная

Модели героев и предметов — в отдельном репозитории `dota-ruiner-models` (GitHub Pages):

```bash
python tools/build_models.py C:/Claude/dota-ruiner-models   # нужен Source 2 Viewer CLI (VRF) и tools/node (npm i)
python tools/fix_idle.py C:/Claude/dota-ruiner-models       # стойка для героев, у которых она не «idle»
```

Предмет приходит без скелета: его кости сводятся к костям героя по имени (или ближайшему предку), сайт перепривязывает
вершины к скелету героя в `js/viewer3d.js`.

## Обновить данные после патча

```bash
python tools/build_consts.py   # герои и предметы OpenDota
python tools/build_icons.py    # портреты героев и иконки предметов из pak01_dir.vpk
python tools/build_items.py    # косметика: наборы, слоты, русские названия, иконки
```

## Локально

```bash
node dev.mjs        # http://localhost:3141
node test.mjs       # прогон модели на tools/sample-match.json
```
